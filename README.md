# ชีวิตเดียวแห่ง Runeterra

เกมจำลองชีวิตแฟนเมดบนทวีป Runeterra ทั้งเกมอยู่ในไฟล์เดียวคือ [`index.html`](index.html) เปิดในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม

เล่นออนไลน์ได้ที่ [fsablock.github.io/testgame](https://fsablock.github.io/testgame/)

## วิธีเล่น

1. เปิด `index.html` หรือลิงก์ด้านบน
2. เลือกความยาวของหนึ่งชีวิต: ประมาณ 15 นาที, 30 นาที หรือ 1 ชั่วโมง
3. ยืนยันว่าอายุ 15 ปีขึ้นไป
4. กด **เกิด**

ระหว่างเล่นหยุดชั่วคราว เร่งความเร็ว หรือเปิดโหมดอัตโนมัติได้ แต่ละปีมีทางเลือกที่เปลี่ยนอาชีพ ครอบครัว สุขภาพ และที่อยู่

## ในหนึ่งชีวิต

ตัวละครเกิดแบบสุ่ม ทั้งแคว้น เผ่าพันธุ์ ฐานะครอบครัว และพรสวรรค์ จากนั้นใช้ชีวิตทีละปีจนจบ

- **12 แคว้น:** เดมาเซีย, น็อกซัส, ไอโอเนีย, พิลโทเวอร์, ซอน, เฟรย์ลยอร์ด, บิลจ์วอเทอร์, ชูริม่า, อิกซ์ทัล, ทาร์กอน, เกาะแห่งเงา, แบนเดิลซิตี้
- **เผ่าพันธุ์ตามถิ่นเกิด:** มนุษย์, ยอร์เดิล, วาสทาญ่า, ลูกครึ่งวาสทาญ่า, ไอซ์บอร์น, โทรลล์, มิโนทอร์, ผู้ถูกหมอกแตะ, ผู้ถูกความว่างแตะ
- **เวทขึ้นกับแคว้น:** เดมาเซียล่าผู้ใช้เวท น็อกซัสใช้เวทเป็นเครื่องมือ ไอโอเนียกับอิกซ์ทัลผูกกับเวทวิญญาณ ทาร์กอนอาจถูกสุริยันหรือจันทราเลือก
- **สิ่งที่ดำเนินไปพร้อมชีวิต:** การเรียน อาชีพ ครอบครัว ข่าวของโลก และภาพเหมือนที่เปลี่ยนตามวัย

ชีวิตที่กำลังเล่นจะไม่ถูกบันทึก รีเฟรชหน้าแล้วต้องเกิดใหม่ ชีวิตที่จบแล้วจะอยู่ในอนุสรณ์ของเบราว์เซอร์เครื่องนั้น

## หมายเหตุ

เกมแฟนเมดที่ไม่เป็นทางการ ไม่เกี่ยวข้องกับ Riot Games ชื่อและโลกของ Runeterra และ League of Legends เป็นของ Riot Games, Inc.

มีเนื้อหาเกี่ยวกับความตาย สงคราม อาชญากรรม และการพึ่งพาสารเสพติด หากรู้สึกไม่สบายใจ โปรดคุยกับคนใกล้ชิด หรือโทรสายด่วนสุขภาพจิต **1323** (ประเทศไทย)
